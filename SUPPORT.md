# Suporte e testes

Use a versão mais recente das [releases oficiais](https://github.com/NeiveZ/neivboom/releases). O projeto está em beta; resultados de gargalo são hipóteses baseadas nas métricas disponíveis, não garantia de FPS máximo.

Para problemas comuns, abra uma issue com versão, Windows, hardware relevante, passos e mensagem de erro. Revise os anexos para remover dados pessoais. Não compartilhe credenciais.

Para falhas de segurança, use o canal privado descrito em [SECURITY.md](SECURITY.md).

Se o Windows bloquear o instalador, não desative as proteções. A versão de testes ainda não tem assinatura de editor confiável; aguarde uma distribuição compatível com as políticas de segurança do seu dispositivo.

Antes de fechar programas, salve seu trabalho. Antes de alterar drivers, faça backup. Não teste alterações USB em periféricos indispensáveis para controlar o computador.
